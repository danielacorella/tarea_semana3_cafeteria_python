# Descripción

Programa interactivo desarrollado en Python que simula un sistema de pedidos para una cafetería.

Permite consultar un menú de seis productos con sus precios, registrar pedidos indicando el nombre del producto y la cantidad, consultar los subtotales y finalizar la compra calculando un porcentaje de propina y el total a pagar.

El programa utiliza diccionarios, listas, estructuras condicionales, bucles `for` y `while`, y validaciones de datos ingresados por el usuario.

## Ejecución

Abrir el archivo `tarea_cafeteria_danielacorella.py` en Visual Studio Code y ejecutarlo con Python.
